# Build our own book-grounded Clean Code plugin instead of adopting or forking @george2f/eslint-plugin-clean-code

agent-org uses `@george2f/eslint-plugin-clean-code` (A11-95). A11-107's audit found autofixes that change what code does: `no-dead-code` turns `import type` into a runtime import, and `no-clutter` removes private constructors. It also found rules that misfire on this codebase, and the plugin ships as a minified bundle with no source maps. We will build `eslint-plugin-clean-code` from scratch instead. Each rule is traced to a quoted passage of *Clean Code, 2nd Edition* through bookCTX, and every A11-107 finding is one of its regression tests. It will replace `@george2f` in agent-org once it ships. Forking was rejected because a fork would bring the same bugs with it and leave the rules without a source in the book.
